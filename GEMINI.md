# Agent Guide

This project is a Tetris game written in Rust.

## Tech Stack
- Language: Rust
- UI: `ratatui` crate (terminal UI)
- Development style: TDD (Test-Driven Development)

## Development Principles
- Implement features incrementally using TDD.
- Keep the game logic independent from the UI as much as possible.
- Prefer clear, simple abstractions over premature optimization.

## Documentation
- Notes, learnings, and retrospectives discovered during development
  are written as Markdown files under the `docs/` directory.
- These documents may include design decisions, Rust-specific insights,
  and lessons learned while building the project.

## Contribution Notes
- Follow existing code style and module structure.
- Add or update tests when modifying behavior.
- Keep documentation up to date when new concepts are introduced.
